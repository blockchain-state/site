# mathr.ch

Threshold site for **Math.R** — a coordination layer built above the existing internet.

## Stack

- Astro 5 + TypeScript + MDX
- Plain CSS (no Tailwind in MVP), CSS variables for the palette
- Cloudflare Pages for hosting (Phase 0)
- GitHub → Cloudflare → mathr.ch

## Palette

| Token | Hex | Use |
|---|---|---|
| `--anthracite` | `#171A1C` | text |
| `--warm-paper` | `#F4F1EA` | background |
| `--deep-water` | `#2A5F6F` | environment accent |
| `--trace-amber` | `#C89B5A` | trace / memory / contribution |
| `--muted-silver` | `#9CA3A6` | secondary |

## Commands

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # → ./dist
npm run preview
```

## Character

Not a SaaS landing. Threshold document. Swiss protocol minimalism + archival warmth.
Avoid: trusted-by, get-started, AI buzzwords, founder cult, motivational language.
